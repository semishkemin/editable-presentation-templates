## Using the templates

You do not need Python to use the finished templates.

Download a PowerPoint file, open it in desktop PowerPoint, and edit the text, colors, fonts, and shapes directly.

The slides use a 16:9 layout and contain real editable PowerPoint objects rather than flattened images.

To download the entire collection, use **Code → Download ZIP** from the repository homepage.

## Source code

The Python source code used to generate the templates is included in this repository.

Python 3.10+ is recommended.

Install the shared dependencies with:

```bash
python -m pip install -r requirements.txt
```

Each template's folder contains its own usage notes and customization details.

## Previews

PNG previews are included so you can inspect the templates without opening PowerPoint.

The PNG files are static previews. The PowerPoint files contain the editable versions.
